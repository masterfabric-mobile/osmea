# OSMEA SMTP Settings (WordPress Plugin)

This plugin adds a simple SMTP settings page to WordPress admin and applies the settings to emails sent via `wp_mail()`.

## Install

1. Copy `docs/plugins/osmea-smtp-settings/` into your WordPress plugins directory: `wp-content/plugins/osmea-smtp-settings/`
2. Activate **OSMEA SMTP Settings** in **Plugins**.
3. Go to **Settings → OSMEA SMTP** to configure.

## Features

- SMTP host/port/encryption
- Optional authentication (username/password)
- Optional "Force From" name/email
- Test email sender
- Optional `wp-config.php` constant overrides (see settings page)
